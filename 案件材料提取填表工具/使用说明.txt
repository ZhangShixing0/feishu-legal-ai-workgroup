案件材料提取填表工具 1.0

一、功能
1. 上传一个案件材料 ZIP 压缩包和一个 XLSX 案件信息表。
2. 在本机读取 PDF、Word、图片、文本及文件夹名称，自动匹配 Excel 表头。
3. 压缩包中没有可靠信息的字段填“无”，并在结果 Excel 中标黄。
4. 生成前可在网页中逐项核对、修改；黄色行表示材料中未找到可靠信息。
5. 同一表中已存在相同“贷款账号”或“序号”时，更新该行；否则在表尾新增一行。
6. Excel已有值但材料未验证时显示“Excel保留”；材料值不一致时显示“值有冲突”。
7. 多案件压缩包会按“序号XXX.xlsx”和行内标识选择目标案件；无法唯一确定时停止处理。

二、启动
1. Windows 10 或 Windows 11。
2. 安装 Python 3.10 或更高版本，并在安装时勾选“Add Python to PATH”。
3. 解压整个工具文件夹，双击 run.bat。
4. 浏览器会自动打开 http://127.0.0.1:8777/ 。

三、使用
1. 选择 ZIP 案件材料。
2. 选择 XLSX 表格（表头应与示例表一致或包含同名字段）。
3. 点击“开始提取”。图片较多时，离线 OCR 可能需要几十秒。
4. 在结果表中核对低置信度和缺失字段，可直接修改。
5. 点击“生成并下载 Excel”。原始 ZIP 和 Excel 不会被覆盖。
6. “Excel保留”不代表材料已证明该值；“值有冲突”必须结合基准日和原始证据人工确认。

四、隐私与注意事项
1. 全程离线处理，不调用外部 AI 或第三方接口。
2. 处理副本保存在本工具 outputs 文件夹，默认启动时清理 24 小时前的任务。
3. 身份证号、手机号等按原文完整处理，不做脱敏。
4. OCR 可能受水印、低清晰度、倾斜扫描影响。请务必核对“需核对”和黄色缺失项。
5. 本工具只做材料整理，不代替律师对事实、证据和法律关系的专业审查。

五、停止
关闭启动时出现的命令窗口，或在窗口中按 Ctrl+C。
