律书生成台（完整案件信息版 0.6.0）

一、运行环境
1. Windows 10 或 Windows 11。
2. 已安装 Python 3.10 或更高版本，并在安装时勾选“Add Python to PATH”。
3. 生成过程不需要安装 Microsoft Word；打开下载的DOCX时需要Word或兼容办公软件。

二、启动方法
1. 首次使用先双击“setup.bat”安装独立虚拟环境和依赖。
2. 双击“run.bat”。
3. 浏览器会自动打开 http://127.0.0.1:8765/ 。
4. 如浏览器没有自动打开，可手工输入上述地址。

三、使用方法
1. 在左侧粘贴或填写案件信息。
   支持Excel表头对应的完整连续文本，即使字段之间没有换行、空格或冒号也可识别。
2. 点击“生成预览”。
3. 右侧立即显示与Word内容、表格一致的完整HTML版式预览。
4. 点击右上角“Word”下载完整DOCX。
5. 网页预览中的所有新填信息会标黄；下载的Word不带黄色底色。
6. 身份证号会在录入框、网页预览和Word中完整显示。

四、停止方法
关闭启动时出现的黑色命令窗口，或在该窗口按 Ctrl+C。

五、隐私说明
单独运行律书生成台时，所有材料仅在当前电脑处理，不会自动上传或外发。

飞书工作群模式会让原始材料先进入飞书内部群，再下载到受控服务器；必须限制群成员、机器人权限和允许群白名单。

服务器版说明
服务器共享模式下，案件材料会通过HTTPS发送到本律所服务器处理，不调用外部AI或第三方接口；生成文件默认在24小时后自动清理。公网部署时必须启用HTTPS和访问密码，不要开放8765端口。

六、当前验证范围
律书生成台仅支持“金融借款合同纠纷民事起诉状（完整案件信息版）”。材料 ZIP、Excel 和飞书双 AI 员工由仓库中的独立服务提供，完整说明见 README.md。
